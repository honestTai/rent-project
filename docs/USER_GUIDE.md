# 操作手册

文档站中的截图可点击打开原图，便于查看较小的按钮和表格文字。

本手册按当前前端路由、按钮和后端条件逐页编写，覆盖 **33 个页面与状态入口**，并单独说明关键新增/编辑弹窗、支付宝、e签宝及自动代扣配置。每页配本地演示截图，全部使用虚构数据；不复用旧客户手册或真实业务截图。

安装见 [快速开始](QUICKSTART.md)，初始化见 [初始化说明](INITIALIZATION.md)，服务维护见 [部署说明](DEPLOYMENT.md)。本仓库包含中台、租赁运营后台和支付宝小程序服务端接口，**不包含可直接发布的支付宝小程序前端**。外部应用与商户能力由部署方接入。

## 2. 第一次使用

1. 按初始化说明生成独立密码与配置并导入空白环境。初始管理员账号是 `admin`，密码由初始化过程设置，没有共享默认密码。
2. 打开中台入口。前端开发模式默认中台 `http://127.0.0.1:8084/`、租赁后台 `http://127.0.0.1:8083/`；部署入口以实际配置为准。
3. 在统一登录输入后台账号和密码。租赁登录会跳转中台，不单独创建第二套员工账号。
4. 在个人中心修改自己的密码；在系统总览、监控和日志确认网关、中台、租赁服务可用。
5. 建立日常角色与员工账号，授权后重新登录检查菜单和按钮。后台员工与小程序用户是不同数据。
6. 学习时先查看商品、目录、订单详情与分析。接入真实业务前，再按集成分册配置自己的支付宝应用、存储、协议主体、e签宝和回调。

空订单、零指标或空用户列表可能只是没有业务数据。演示订单不会自动拥有真实的支付交易、押金冻结、电子签署或代扣协议。

## 3. 所有列表与弹窗的共通操作

| 控件 | 如何使用 |
| --- | --- |
| 左侧菜单 | 按当前账号权限显示；展开分组后进入具体页面。 |
| 顶部折叠菜单图标 | 收起或展开侧栏，增加内容区域；不影响当前权限。 |
| 顶部 Logo | 中台返回系统总览，租赁端回到默认业务入口。 |
| 顶部账号入口 | 进入个人中心或退出登录。修改密码、角色或账号状态后可能需要重新登录。 |
| 输入框清除图标 | 清空该字段；是否立即查询由页面决定。中台多处修改条件自动查询，租赁业务页提供查询/重置。 |
| 下拉框 | 选择指定值；支持清空的下拉可取消该限制。有些选择器支持输入文字筛选候选。 |
| 查询 / 刷新 | 按当前页面规则重新取数；售后页查询会读取远端，不是纯本地检索。 |
| 重置 | 恢复页面查询条件；当前订单上下文可能保留固定订单。不会删除业务数据。 |
| 分页 | 页码切换当前结果，条数选择改变每页数量。列表为空时先检查条件和错误提示。 |
| 复选框 | 单行选择或当前列表批量选择，批量操作前核对范围。 |
| 编辑 / 新增 | 打开表单；带必填约束的字段需完成后提交。打开弹窗本身不保存。 |
| 确认 / 保存 / 生成 | 校验当前表单，部分操作随后显示统一“操作确认”弹窗；最后确认才发送请求。不同页面可能调用外部平台，提交前按对应分册核对。 |
| 取消 / 右上角关闭 | 对未提交表单退出本次编辑。当前不是所有删除和状态动作都有二次弹窗，不能用“先点看看”判断。 |
| 图片预览 | 点击已有商品或身份图片打开预览；公开反馈时不要附带真实个人资料。 |
| 外部链接 | 源码、文档、赞助商及签署文件等入口可能在新窗口打开。 |

页面底部提供“源代码 / AGPL-3.0”“操作文档”“赞助 HRouter”。维护自己的 fork 时，通过构建变量 `VITE_SOURCE_URL` 指向实际运行版本对应的源代码。

### 统一操作确认

中台配置、通知、任务、角色的保存与删除，角色权限保存、用户角色页的绑定保存，以及后台用户新增/编辑/删除/重置密码，会在请求发送前显示“操作确认”。租赁端商品与 SKU 保存/删除、上下架/置顶/同步、小程序用户封禁/解封、报表生成和部分订单动作也使用该弹窗。

在“操作确认”中点“确认”才发送请求；点“取消”或关闭不发送本次请求。表单的确认与请求确认是两步，不能把看到表单关闭或一条成功提示等同于外部平台处理完毕。轮播图状态动作、部分身份审核与合同操作等没有这层确认，具体以分册列出的步骤为准。

### 显示设置：每个控件的作用

订单、商品、用户、台账、分析和报表等页面提供“显示设置”。打开后：

1. 选择“模块”“字段”或“操作按钮”分类；具体分类随页面功能变化。
2. 勾选需要显示的项目。锁定项目不可取消，订单“概览”属于必须保留的内容。
3. 在“展示顺序”列表点“上移 / 下移”。第一项不能上移，最后一项不能下移。
4. 点“恢复当前默认”只恢复当前分类的默认选择与顺序。
5. 点“保存设置”应用并保存浏览器中的本地偏好；点“取消”或关闭不应用本次草稿。

显示设置不授予权限、不修改订单状态，也不替代服务端校验。更换浏览器、站点来源或清除本地存储后，偏好可能恢复默认。

### 图片查看器

商品、SKU、轮播图和部分订单图片使用同一图片查看器。打开后，左右箭头切换多张图片；单张图片没有可切换目标。底部“缩小 / 放大”调整显示比例，百分比显示当前缩放；“旋转”“镜像”改变预览方向，“原始大小”恢复原尺寸显示。下载图标请求保存当前图片，能否完成取决于图片地址、浏览器与跨域条件。右上角关闭返回原页面。

这些操作只影响查看或本地下载，不替换服务器图片，也不修改身份审核结果。编辑商品时移除轮播图使用的是表单中的删除图标，与关闭查看器不同。

## 4. 常见流程的阅读顺序

| 想完成的工作 | 操作路径 |
| --- | --- |
| 新增员工并限制其权限 | 中台角色授权 → 用户管理 → 分配角色 → 重新登录核对。 |
| 准备商品供小程序展示 | 商品基础信息 → SKU → 图片/类目 → 本地上架与同步日志 → 目录绑定 → 轮播图。 |
| 处理租赁交付 | 订单查询 → 详情核对 → 身份/风险 → 已支付后发货 → 按合同条件收货 → 归还签收 → 选择完结类型。 |
| 核对押金扣减 | 订单押金 → 扣减表单 → 售后记录 → 确认/扣款条件 → 支付与远端终态 → 台账。 |
| 接入电子合同 | e签宝配置 → 正确协议和签署人资料 → 订单发起签署 → 用户签署 → 回调/查询 → 签署文件与回传。 |
| 接入自动代扣 | 具备产品权限 → 分期订单与待收账单 → 用户签约授权 → 回调 → 按需启用任务 → 核对扣款结果。当前后台主动签约入口关闭。 |
| 做经营复盘 | 统一周期 → 看板 → 对应专题 → 订单/台账核对 → 报表中心详情或补生成/导出。 |
| 排查问题 | 发生时间与错误摘要 → 对应订单/台账 → 系统日志 → 监控 → 配置及外部回调。 |

## 5. 当前界面必须知道的边界

- 订单“账单下载”目前是提示占位，没有可下载文件；周期报表的“导出”在报表详情内。
- 关闭订单、退款和用户封禁等有统一操作确认；部分身份审核、合同与轮播图动作直接请求。先按分册核对每个按钮的具体行为，不能为了查看后续界面试点业务动作。
- 后端包含自动代扣能力，但后台主动签约按钮当前隐藏。分期、协议签约、到期扣款和实付是分别核对的状态。
- 商品上架、协议生成、接口返回成功与外部平台审核/签署/资金终态不能互相替代。
- 演示环境显式关闭自动代扣签约入口与扣款任务，保持第三方凭证为空；截图只查看本地虚构数据和表单。

## 6. 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 登录失败或循环跳转 | 账号密码、请求状态、网关/中台连接、Redis 登录态、SSO 与前端 API 地址。 |
| 看不到菜单或按钮 | 启用角色与授权 → 重新登录 → 显示设置 → 订单状态与来源数据。 |
| 配置已填仍报缺失 | 系统编码、键名、启用状态、空值、中台连接、读取缓存。 |
| 图片失败或不能同步 | 存储参数、上传权限、资源路径/域名，以及第三方是否可访问图片。 |
| 发货、收货受阻 | 是否已支付、配送方式、风险确认、身份审核、电子合同要求。 |
| 支付/退款/扣款状态不一致 | 交易号、远端查询、回调验签与到达、订单/账单映射、台账。 |
| 日志找不到文件 | 服务是否写文件日志、日志来源目录、挂载路径和读取权限。 |
| AI 工具不可用 | Agent 服务、网关、模型配置、用户权限及所需只读数据库/MCP 连接。 |
| 页面白屏或资源 404 | 前端部署路径与 `VITE_BASE_URL`，地址中的 Hash 路由 `#` 是否保留。 |
