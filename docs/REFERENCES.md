# 官方资料

以下入口用于核对协议、平台接入和部署工具。外部平台页面及权限要求以访问时的官方内容为准。

| 资料 | 用途 |
| --- | --- |
| [GNU AGPL v3](https://www.gnu.org/licenses/agpl-3.0.html) | 许可证全文，特别是网络交互场景的源码提供条款 |
| [GitHub：GNU AGPLv3](https://choosealicense.com/licenses/agpl-3.0/) | 许可条件与 SPDX 标识；本仓库选择 AGPL-3.0-only |
| [支付宝文档中心](https://opendocs.alipay.com/mini) | 小程序应用创建、开发工具、准入与平台 API 的官方入口 |
| [支付宝开放平台](https://open.alipay.com/) | 应用、接口权限、应用密钥与业务能力配置 |
| [e签宝文档中心](https://open.esign.cn/doc/opendoc) | 电子签名 API、合同文件签署、模板和对接指南 |
| [MySQL 8.0 文档](https://dev.mysql.com/doc/refman/8.0/en/) | 数据库、账号授权、备份恢复 |
| [Docker Compose 文档](https://docs.docker.com/compose/) | 服务编排、环境变量和网络 |
| [MkDocs 部署文档](https://www.mkdocs.org/user-guide/deploying-your-docs/) | 生成和托管本项目文档站 |
| [GitHub Pages 文档](https://docs.github.com/en/pages) | 文档站发布与域名配置 |
| [HRouter](https://hrouter.net/) | 本项目赞助商，服务介绍与接入入口 |

README 的组织方式参考维护者的 [ZZ Geo / geo-console](https://github.com/honestTai/geo-console)。
本仓库的功能说明以当前代码为依据，未把参考项目的功能或截图用于租赁系统。
