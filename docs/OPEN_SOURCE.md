# 开源与赞助

Rent Project 的自有源码采用 **AGPL-3.0-only**，可依协议使用、修改、部署和商用。
完整条款见 [LICENSE](https://github.com/honestTai/rent-project/blob/main/LICENSE)。

修改版通过网络与用户交互时，应按第 13 条向这些用户显著提供对应源码的获取方式。
分发时同样需要履行适用条款。前端页脚已提供源码入口，修改版部署可用 `VITE_SOURCE_URL`
指定对应源码地址。[GitHub 的 AGPL 说明](https://choosealicense.com/licenses/agpl-3.0/)提供了许可条件概览。

第三方代码保留其自身许可，见 [第三方声明](https://github.com/honestTai/rent-project/blob/main/THIRD_PARTY_NOTICES.md)。
运行需要的云资源、支付宝应用、存储和模型服务由部署者准备。
