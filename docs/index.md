# Rent Project 官方文档

**租赁业务管理系统**，连接配置中台、商品运营、租赁订单、履约、售后和经营分析。

源码采用 **AGPL-3.0-only**，包含 Java 服务端、两个 Vue 后台、初始化数据与可选分析 Agent。
小程序前端和第三方平台账号需自行准备。

特色能力包括支付宝租赁与芝麻信用免押、e签宝电子合同、分期代扣、履约售后、统一权限配置与经营分析。

![经营看板：本地虚构演示数据](assets/screenshots/rent-dashboard.png)

图文手册覆盖 33 个页面，配有 53 张本地演示截图，逐项说明按钮、表单字段、权限和操作条件。
